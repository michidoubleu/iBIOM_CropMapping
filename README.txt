Codebase created by Michael Wögerer - IBF

This code can be used to distribute crops on a given LU map.
Setup specifically for LAMASUS LUM map and GLOBIOM crop statistics, to update GLOBIOM inputs.
Runs locally: copy user_config_TEMPLATE.R to user_config.R and run main.R (see README.md).

Known issues:
Mixed and/or CAPRI priors fail when used for GLOBIOM uptake.
Too much runtime for full local compilation
